# 🎥 video-meet-ai-module

A smart video interview platform built with Node.js and TypeScript. This module allows HR managers to create, schedule, and manage AI-assisted video interviews, while candidates can join, accept, or reject interviews.

## 🚀 Features

- 🧑‍💼 HR & Candidate roles
- 📅 Schedule & manage interviews (CRUD)
- 🎥 Record video interviews
- 🔐 Auth system for users (JWT-based)
- ✅ Candidate can accept/reject interviews
- 🧠 AI module integration placeholder

## 📦 Tech Stack

- **Backend:** Node.js + Express + TypeScript
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT
- **Frontend:** React
